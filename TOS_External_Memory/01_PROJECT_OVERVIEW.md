# 01 — TOS Project Overview

## Identity
**TOS = Trading Operations System**. A multi-agent system for organizing and operationalizing financial-market analysis and trading operations, using accumulated market/algorithmic knowledge and ICT (Inner Circle Trading) as a major knowledge foundation.

## Why TOS exists
The problem is not simply lack of knowledge. A human may know many concepts and relationships while struggling to process many inputs simultaneously, maintain attention during real-time work, synthesize large amounts of information consistently, and execute a repeatable workflow. TOS addresses this by decomposing work into specialized agents.

## Human role
- Engineer and system owner
- Architect
- Final decision/approval authority
- Overall monitor

## Core design
TOS is layered:
1. Analysis
2. Risk Measurement
3. Timing / Scheduling
4. Monitoring

Analysis is the first layer to engineer.

## Analysis dimensions
- Context / Content
- Time Alignment
- Price Alignment
- Multi-timeframe / Macro Review
- Models / Setups

Time Alignment and Price Alignment are deliberately distinct analytical responsibilities.

## Current strategic decision
Do **not** finalize the complete TOS agent inventory yet. First reconstruct ICT accurately from primary teaching; then derive the final agent decomposition from the resulting knowledge structure. This prevents the architecture from being limited by one person's current mental representation of ICT.
