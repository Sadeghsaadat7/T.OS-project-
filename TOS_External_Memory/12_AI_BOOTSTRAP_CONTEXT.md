## Prompt standard
Use Identity, Role, Mission/Goal, Context, Inputs, Action, Rules, Do/Don't, Source Policy, Validation, Output Format, Handoff, Iteration/Escalation and Version. Base method: GCAO+V = Goal, Context, Action, Output, Validation.
