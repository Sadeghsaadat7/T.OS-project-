# 11 — TOS Roadmap

## Stage A — Prompt engineering foundation
**Status: working standard established.** Seven-page notebook consolidated into GCAO+V plus TOS-specific extensions.

## Stage B — ICT Knowledge Acquisition System
**Current priority.** Define master prompt and specialist prompts; provide primary sources; inventory ICT; run parallel research; audit; build Master ICT Knowledge Base.

## Stage C — ICT knowledge validation
Coverage matrix, evidence audit, chronology/evolution, conflict registry, terminology normalization and unresolved-gap registry.

## Stage D — Final TOS agent inventory
Only after Stage C: derive responsibilities, preserve Time/Price separation, map macro/micro roles and dependencies, assign layers.

## Stage E — Agent specifications
Role, mission, scope/non-scope, inputs, outputs, authority, validation, handoff, escalation and tests.

## Stage F — TOS prompts
Apply canonical prompt standard to each agent.

## Stage G — Orchestration
Workflow, dependency graph, state transitions, conflict handling and controller/coordinator logic.

## Stage H — Testing
Unit, integration, historical/replay, adversarial, incomplete-data and conflicting-data scenarios.

## Stage I — Operational system
Monitoring, logging, version control, audit trail and controlled knowledge-base updates.
