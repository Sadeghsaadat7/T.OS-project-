# 09 — Research Workflow

## Phase 1 — Source discovery
1. Identify primary ICT sources.
2. Inventory playlists.
3. Inventory videos.
4. Record URLs and metadata.
5. Identify inaccessible/uncertain material.
6. Build source map.

## Phase 2 — Parallel research
```text
Source Scout
    ├── Curriculum Researcher
    ├── Concept Researcher
    ├── Time/Price Researcher
    └── Model/Strategy Researcher
              ↓
        ICT Auditor
              ↓
      Knowledge Architect
```

Parallelization improves coverage while preserving specialization.

## Phase 3 — Evidence extraction
For each material concept: identify source, context, exact terminology, evidence, status and uncertainty.

## Phase 4 — Audit
Check primary-source support, terminology, chronology, contradictions, unsupported inference and third-party contamination.

## Phase 5 — Knowledge integration
Build source map, concept inventory, terminology dictionary, time framework, price framework, model/setup library, evolution map, evidence database and knowledge graph.

## Phase 6 — Coverage assessment
Use a matrix such as:

| Domain | Sources found | Sources reviewed | Claims verified | Gaps | Conflicts |
|---|---:|---:|---:|---:|---:|
| Concepts | | | | | |
| Terminology | | | | | |
| Time | | | | | |
| Price | | | | | |
| Models | | | | | |
| Setups | | | | | |
| Multi-timeframe | | | | | |

Do not call research complete while important gaps are undocumented.

## Phase 7 — Agent decomposition
Only after sufficient knowledge coverage: identify functional domains, independent decision responsibilities, inputs/outputs, boundaries and minimal-overlap specialist agents.

## Phase 8 — Prompt engineering
Specification → GCAO+V prompt → boundaries → output → validation → handoff → tests → iteration → version.

## Phase 9 — Orchestration
Define dependencies, parallel/sequential tasks, authority, conflict resolution, escalation and state management.

## Phase 10 — Operational testing
Run controlled scenarios, including historical/replay, adversarial, incomplete-data and conflicting-data cases.
