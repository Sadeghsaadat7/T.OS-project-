# TOS — External AI Memory / Trading Operations System

## Purpose
Portable external memory for the TOS (Trading Operations System) project, designed to let different AI systems reconstruct the project's context, architecture, prompt standards, research methodology and roadmap without relying on one chat history.

## Current direction
The project has moved from personal ICT study to system engineering. The immediate objective is to build an ICT Knowledge Acquisition System: multiple research agents first reconstruct Michael Huddleston's teaching from primary sources, then audit and organize it, and only after that derive the final TOS agent inventory.

## Core architecture
1. Analysis
2. Risk Measurement
3. Timing / Scheduling
4. Monitoring

Within Analysis, preserve Context/Content, Time Alignment, Price Alignment, Multi-timeframe/Macro Review, and Models/Setups as distinct analytical responsibilities until validated research establishes a better architecture.

## ICT source hierarchy
1. Direct original teaching by Michael Huddleston / ICT
2. Official ICT publications/channels
3. Archived copies of original ICT teaching
4. Third-party transcripts/archives for discovery or verification
5. Third-party explanations only as secondary references

Third-party interpretations must never be presented as ICT doctrine.

## Research status
`PRIMARY-VERIFIED`, `SECONDARY-VERIFIED`, `UNVERIFIED`, `INTERPRETATION`, `CONFLICT`, `UNKNOWN`.

## Human role
The user remains the engineer, project owner, architect and final monitor. Agents are specialized components with bounded responsibilities.
